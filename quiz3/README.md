Code Documentation:
For my php website implementation, my main idea was to change my index.html into an index.php that dynamically uploads information from
my phpmyadmin database tables, into my website. In order to implement this, I created a resources folder that holds my conn.php, header.php,
and footer.php. I put them in resources because the header and footer are added into all of my pages. After that, I created a php file for each
of my tables in phpmyadmin, so that I can load the data from the table into my files. I did this by including each of these files into my index.php
or my projects.php. In order to implement the login and logout, I made a login.php that handles the logging into the website, and then log out
to destroy the session. The admin.php gives admins more permissions after they log in with an admin account. I feel like I had most of the implementation down, it was just some small errors in my file paths, or a small variable name problem that made my code not be able to be shown correctly. I was close to completing the assignment.
